# customFormHelpComponent

## Description

This component is used for displaying a simple link that can output help when clicked on

## API Version

66.0

## Exposed

true

## Master Label

## Targets

- `lightning__FlowScreen`

## Builder Properties

| Target(s) | Property | Label | Type | Role | Default | Description |
| --- | --- | --- | --- | --- | --- | --- |
| lightning__FlowScreen | helpLinkText | Help Link Text | String | inputOnly |  | This is the test that you want to use for the help link |
| lightning__FlowScreen | helpMessage | Help Message | String | inputOnly |  | This is the rich/plain text that you want to display in your help message |
| lightning__FlowScreen | fontSize | Font Size | String | inputOnly |  | Set the font size class that you want to apply in here view slds1 text page for available options |
| lightning__FlowScreen | useModal | Use Modal | Boolean | inputOnly | False | Set this to true if you want the help text to appear in a modal on screen, by default it will appear beneath |
